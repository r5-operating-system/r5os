Built for R5

Aomi is a native Haiku/R5 browser window around a single engine contract (BWebContentView). Bookmarks stay ordinary Tracker files in WebPositive/Bookmarks, menus use standard R5 shortcuts, and WebPositive stays installed as the default browser while Aomi is experimental.
