# Brand kit (the website moved)

The R5 website is <https://r5-operating-system.github.io/>, built from its own repository
[r5-operating-system/r5-operating-system.github.io](https://github.com/r5-operating-system/r5-operating-system.github.io).
Change the site there, not here. Its texts are in `content.toml`, its screenshots in `screenshots/`.

This folder keeps the brand material: the logos and symbols, the lockups, the boot splash,
`brand-guide.html`, `wallpapers.html` and `brand-kit/`. Their menus link to the new site.

The site reads What's new (`distro/WHATSNEW`), the build number (`distro/BUILD`), the merged
pull requests and the R5Book (`docs/r5book/`) from `main` in this repository every day.
