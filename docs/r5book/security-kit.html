The Security Kit

Password hashing, key derivation, authenticated encryption, wiped secret memory, and cryptographic random bytes in BeOS style. All classes live in namespace BSecurityKit and wrap unmodified Monocypher 4.0.2 (CC0-1.0) with no custom cryptographic primitives.

What is in this page

  • BSecureBuffer — Secret memory wiped on clear and destruction.
  • BRandom — Cryptographically strong random bytes.
  • BPasswordHash — Argon2id key derivation and PHC password hashes.
  • BSealedData — XChaCha20-Poly1305 authenticated encryption for buffers and files.
  • R5SD wire format — Header, nonce, MAC, and associated data layout.
  • Example — Deriving a key, sealing a secret, and opening it back.

Key storage stays BKeyStore. To store application passwords or tokens for the signed-in account, continue to use Haiku's BKeyStore (<KeyStore.h>). The Security Kit provides the cryptographic building blocks underneath R5's keystore and sign-in password hashing, and is available to any program that needs Argon2id or authenticated encryption.

BSecureBuffer

class

A non-copyable byte buffer for keys, passwords, and decrypted secrets. Every Wipe(), Clear(), reallocation, and destruction overwrites the buffer with Monocypher's crypto_wipe() so the compiler cannot optimize the zeroing away.

BSecureBuffer(); explicit BSecureBuffer(size_t size);

Creates an empty buffer or allocates size zeroed bytes. Check InitCheck() after using the sized constructor.

status_t Allocate(size_t size); status_t SetTo(const void* data, size_t size);

Allocates a new buffer (zeroed for Allocate, copied from data for SetTo), then wipes and frees the previous contents. Passing size == 0 clears the buffer and returns B_OK.

void Wipe(); void Clear();

Wipe() zeroes the bytes in place while keeping the allocation. Clear() wipes, frees, and resets size to 0.

uint8* Data(); const uint8* Data() const; size_t Size() const; bool IsEmpty() const;

Access the raw bytes and size.

bool Equals(const BSecureBuffer& other) const;

Constant-time byte comparison when sizes match. Returns false when sizes differ.

static void WipeMemory(void* data, size_t size);

Wipes any caller-owned memory region (such as a stack password buffer) using crypto_wipe().

BRandom

class

Fills memory with cryptographically strong random bytes read from /dev/urandom (O_CLOEXEC). Handles EINTR and partial reads. On error it wipes the destination buffer and returns B_IO_ERROR or B_ERROR; it never falls back to rand().

static status_t Fill(void* buffer, size_t size); static status_t Fill(BSecureBuffer& buffer); static status_t Fill(BSecureBuffer& buffer, size_t size);

Fills a raw buffer, an existing BSecureBuffer, or allocates and fills a BSecureBuffer of size bytes.

BPasswordHash

class

Argon2id (CRYPTO_ARGON2_ID, RFC 9106) for both key derivation and password storage. Default interactive parameters are memoryKiB = 65536 (64 MiB), passes = 3, and lanes = 1. The Argon2 work area is wiped before being freed.

struct Parameters { uint32 memoryKiB; uint32 passes; uint32 lanes; }; static Parameters DefaultParameters();

Returns the default interactive cost parameters. Stored password hashes and protectors record their own parameters so cost can be raised later without breaking existing data.

static status_t DeriveKey(const void* password, size_t passwordLength, const void* salt, size_t saltLength, const Parameters& params, BSecureBuffer& outKey, size_t outLength = kDefaultHashSize);

Derives outLength bytes (default 32) into outKey. An overload also accepts optional secretKey and associatedData.

static status_t Hash(const char* password, BString& outEncoded, const Parameters& params = DefaultParameters());

Generates a 16-byte random salt and formats a standard PHC string: $argon2id$v=19$m=65536,t=3,p=1$<salt>$<hash> (unpadded standard Base64).

static status_t Verify(const char* password, const char* encoded, bool* _matches);

Strictly parses encoded, re-derives the digest, and compares in constant time. Malformed strings return B_BAD_DATA and set *_matches = false.

static bool NeedsRehash(const char* encoded, const Parameters& params = DefaultParameters());

Returns true when encoded is not a valid Argon2id PHC string or uses weaker parameters than params.

BSealedData

class

Authenticated encryption using a 32-byte key and a fresh random 24-byte nonce per call (XChaCha20-Poly1305 via Monocypher's crypto_aead_lock / crypto_aead_unlock). Any modification to the header, nonce, MAC, associated data, or ciphertext is rejected and outPlaintext is cleared.

static status_t Seal(const BSecureBuffer& key, const void* plaintext, size_t plaintextSize, const void* aad, size_t aadSize, void* outSealed, size_t outCapacity, size_t* _outSize);

Seals plaintext into outSealed (which must not overlap plaintext and must have at least plaintextSize + kOverhead bytes).

static status_t Open(const BSecureBuffer& key, const void* sealed, size_t sealedSize, const void* aad, size_t aadSize, BSecureBuffer& outPlaintext);

Verifies the R5SD header and Poly1305 MAC, then decrypts into outPlaintext. Returns B_BAD_DATA for truncated or unknown-header input and B_NOT_ALLOWED on authentication failure.

static status_t SealToFile(const BSecureBuffer& key, const void* plaintext, size_t plaintextSize, const void* aad, size_t aadSize, const char* path); static status_t OpenFromFile(const BSecureBuffer& key, const char* path, const void* aad, size_t aadSize, BSecureBuffer& outPlaintext);

SealToFile() writes atomically to a sibling temporary file with mode 0600, calls fsync(), and renames it into place. OpenFromFile() reads a regular file and passes it to Open().

R5SD wire format

Every blob produced by BSealedData has a fixed 48-byte overhead (BSealedData::kOverhead):

Bytes 0..3ASCII magic "R5SD"
Byte 4Format version (1)
Byte 5Cipher ID (1 = XChaCha20-Poly1305)
Bytes 6..7Reserved (0x00, 0x00)
Bytes 8..3124-byte random nonce from BRandom
Bytes 32..4716-byte Poly1305 authentication tag
Bytes 48..Ciphertext (same length as plaintext)

The 8-byte header is always prepended to the caller's aad before MAC computation, so tampering with the magic, version, or cipher ID fails authentication.

Example

#include <R5Security.h>

using namespace BSecurityKit;

BSecureBuffer key;
if (BRandom::Fill(key, BSealedData::kKeySize) == B_OK) {
	const char* secret = "account-token";
	const char* aad = "myapp:v1:token";
	BSealedData::SealToFile(key, secret, strlen(secret),
		aad, strlen(aad), "/boot/home/config/settings/myapp/token.sealed");

	BSecureBuffer opened;
	if (BSealedData::OpenFromFile(key,
		"/boot/home/config/settings/myapp/token.sealed",
		aad, strlen(aad), opened) == B_OK) {
		// Use opened.Data(), opened.Size()
	}
}	// key and opened are wiped automatically on scope exit
