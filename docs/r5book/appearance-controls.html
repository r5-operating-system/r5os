Controls & views

Buttons, password fields, pixel-sharp icons, screen placement, and live input meters.

What is in this page

  • BAccentButton — Primary action button in the selection accent color.
  • BAxisBar — Center-zero bar for a value from -1 to 1.
  • BIconView — Displays a bitmap icon at its exact pixel size.
  • BPasswordControl — Password field with a show/hide eye glyph.
  • BScreenArrangement — Interactive monitor layout preview.
  • BTiltLevel — Two-axis bubble level indicator.

BAccentButton

class
Declared in<AccentButton.h>
Librarylibr5ui.so
Derived fromBButton
First userSign in, Unlock on the lock screen

BAccentButton is the one main action of a window, filled with the selection blue and a bold label one step larger than body text.

It is a BButton: the message, the target, MakeDefault(), and Enter work as usual. It is as wide as its label; for the full row, set an explicit maximum width of B_SIZE_UNLIMITED.

Use it for

The single action the window is for: Sign in, Unlock, Install.

Not for

Every button on a row. Restart, Cancel and the like stay plain BButtons.

BAccentButton(const char* name, const char* label, BMessage* message = NULL);

38 pixels high at a 12 point font. The label is white on a dark accent and black on a light one.

BAppearanceKit::BAccentButton* signIn = new BAppearanceKit::BAccentButton(
	"signin", "Sign in", new BMessage(kAttemptLogin));
signIn->SetExplicitMaxSize(BSize(B_SIZE_UNLIMITED, B_SIZE_UNSET));
window->SetDefaultButton(signIn);
See also BPasswordControl Interface guidelines: Buttons Example: Sign in

BAxisBar

class
Declared in<AxisBar.h>
Librarylibr5ui.so
Derived fromBView
First userBGameControllerMotionView (Pitch, Roll, Yaw)

BAxisBar is a rounded bar for a value from -1 to 1 that fills from the middle in the accent color: to the right for positive values, to the left for negative ones, with a tick at 0.

Use it for a value with a center, such as a turn rate or a stick axis. It only shows the value: a value the user drags is a BSlider, and progress is a BStatusBar. The lines come from the panel text color so it follows dark mode, and its height is one line height.

BAxisBar(const char* name);
void SetValue(float value); float Value() const;

Clamped to -1 to 1; NaN is 0. It redraws only when the value changed.

void SetEnabled(bool enabled); bool IsEnabled() const;

False draws the bar gray, the fill included, as a disabled control. True at first.

#include <AxisBar.h>

BAppearanceKit::BAxisBar* pitch = new BAppearanceKit::BAxisBar("pitch");
pitch->SetValue(motion.rotation[0] / 360);
See also BTiltLevel BGameControllerMotionView

BIconView

class
Declared in<R5IconView.h>
Librarylibr5ui.so
Derived fromBView
First userSign in, for the pebble and the clock

BIconView shows one icon at its own pixel size. The view is exactly as large as the bitmap and never scales it.

The header is R5IconView.h because Haiku already has a private IconView.h.

BIconView(const char* name, const BBitmap* icon = NULL);
void SetIcon(const BBitmap* icon); const BBitmap* Icon() const;

The view keeps a copy and changes size with it.

BBitmap* pebble = r5_vector_icon_bitmap(kR5Pebble, sizeof(kR5Pebble), 44);
BAppearanceKit::BIconView* logo = new BAppearanceKit::BIconView("logo", pebble);
delete pebble;
See also Icons Kit: Icon bitmaps Interface guidelines: Icons

BPasswordControl

class
Declared in<PasswordControl.h>
Librarylibr5ui.so
Derived fromBControl
First userSign in and the lock screen

BPasswordControl is a password field with the eye glyph inside it. The open eye shows the password; the crossed-out eye hides it again.

Enter invokes the control's message, or the window's default button. The password is never archived.

BPasswordControl(const char* name, const char* label, const char* text = NULL, BMessage* message = NULL);
const char* Text() const; void SetText(const char* text); BTextView* TextView() const;

Clear the field after every attempt with SetText("").

void SetPasswordRevealed(bool revealed); bool IsPasswordRevealed() const;

The same as a click on the eye.

void SetPlaceholder(const char* text); const char* Placeholder() const;

Gray text while the field is empty.

BAppearanceKit::BPasswordControl* password = new BAppearanceKit::BPasswordControl(
	"password", "", "", new BMessage(kAttemptLogin));
password->SetPlaceholder("Enter password");
See also BAccentButton r5_glyph (R5_GLYPH_EYE) Example: Sign in

BScreenArrangement

class
Declared in<ScreenArrangement.h>
Librarylibr5ui.so
Derived fromBView, BInvoker
First userDisplay; Desktop and Deskbar next

BScreenArrangement shows one or more screens in their places on the desk, each drawn with r5_screen_draw().

A click, Space, or Enter sends the selection message with int32 "be:screen". With dragging on, a released screen snaps against its neighbor and the modification message is sent. The view does not change the screens itself.

struct screen_tile {
	int32		id;			// the caller's id for this screen
	BRect		frame;		// in desktop coordinates
	const char*	name;		// copied by SetScreens()
	bool		main;		// the Deskbar is on this screen
	bool		enabled;	// false draws it dimmed
};
BScreenArrangement(const char* name, BMessage* selectionMessage);
status_t SetScreens(const screen_tile* tiles, int32 count); int32 CountScreens() const; bool ScreenAt(int32 index, screen_tile* tile) const;

The tiles are copied. One screen is centered and keeps its shape; several are scaled together so the gaps stay.

void SetSelected(int32 id); int32 Selected() const;

-1 when none is selected.

void SetDraggable(bool draggable); void SetModificationMessage(BMessage* message);

Dragging needs two screens or more. The message is adopted.

void SetCaption(const char* caption);

A line in the lower left; NULL hides it.

void SetEnabled(bool enabled); bool IsEnabled() const;

False ignores mouse and keys. Settings uses this when the administrator lock is closed.

See also r5_screen_draw() BAdminLockBar

BTiltLevel

class
Declared in<TiltLevel.h>
Librarylibr5ui.so
Derived fromBView
First userBGameControllerMotionView (the Tilt of a game controller)

BTiltLevel is a spirit level seen from above: a circle with a cross, a small center ring, and a bubble in the accent color. x and y run from -1 to 1, left to right and top to bottom, and the bubble stays inside the circle.

Use it for a two-axis value around a center, such as tilt, balance, or stick position. It only shows the value, is square (4 to 10 line heights), and follows dark mode like BAxisBar.

BTiltLevel(const char* name);
void SetValue(float x, float y); float X() const; float Y() const;

Each clamped to -1 to 1; NaN is 0. It redraws only when the value changed.

void SetEnabled(bool enabled); bool IsEnabled() const;

False draws the level gray, the bubble included, as a disabled control. True at first.

#include <TiltLevel.h>

BAppearanceKit::BTiltLevel* level = new BAppearanceKit::BTiltLevel("tilt");
level->SetValue(motion.acceleration[0], motion.acceleration[2]);
See also BAxisBar BGameControllerMotionView
