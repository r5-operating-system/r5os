Cards & layout

Containers and selectable card rows for R5 windows and Settings pages.

What is in this page

  • BActionCard — A single clickable card with a title, subtitle, and tags.
  • BCard — A framed card container that holds child controls.
  • BCardStrip — A horizontal row of selectable picture cards.
  • BCardStripItem — One card item inside a BCardStrip.

BActionCard

class
Declared in<ActionCard.h>
Librarylibr5ui.so
Derived fromBCard, BInvoker
First userSettings home; R5 Hub and Store next

BActionCard is a clickable card with an icon, a title, a summary of up to two lines, and small tags.

It tracks pointer hover, pressed state, and keyboard focus. Clicking the card or pressing Space or Enter calls Invoke(); clicking a tag sends the tag message.

Use it for

A start page of choices: Settings home, the R5 Hub and Store front page.

Not for

A form with child views (use BCard) or a row of selectable items (BCardStrip).

BActionCard(const char* name, BMessage* message);

The message is sent by Invoke(). Without a target, the window is the target.

void SetIcon(const BBitmap* icon); void SetTitle(const char* title); void SetSummary(const char* summary);

The summary wraps to two lines; the second ends with an ellipsis.

int32 AddTag(const char* label); void RemoveAllTags(); int32 CountTags() const; void SetTagColor(rgb_color tint); void SetTagMessage(BMessage* message);

A click on a tag sends the tag message with int32 "be:tag" and "be:label".

void SetHighlighted(bool on);

Draws the card as if the pointer were on it, for example for a search match.

BAppearanceKit::BActionCard* card = new BAppearanceKit::BActionCard(
	"system", new BMessage('open'));
card->SetTitle("System");
card->SetSummary("Display, sound, notifications, virtual memory, and this computer.");
card->SetIcon(icon);
card->AddTag("Display");
See also BCard BCardStrip Interface guidelines: Cards

BCard

class
Declared in<Card.h>
Librarylibr5ui.so
Derived fromBView
First userAbout R5

BCard is a rounded area with a group layout inside it, for a heading or summary that stands on its own.

Children are added through GetLayout(), as with a BGroupView. A child that adopts its parent's colors, such as a BStringView, gets the card's face.

Use it for

A heading or summary in its own area: the About heading, the system information, an account summary, the Sign in header.

Not for

A form the user fills in (stays on the panel), or a stack of pages (use Haiku's BCardView).

BCard(const char* name, card_style style = B_CARD_DOCUMENT, orientation orientation = B_VERTICAL);

B_CARD_DOCUMENT fills with the document background, B_CARD_PANEL with the panel color one step darker. The border is one pixel, the corner radius a quarter of the plain font size, the inner margin B_USE_BIG_SPACING.

void SetStyle(card_style style); card_style Style() const;

Changes the fill and the color children adopt.

#include <Card.h>

BAppearanceKit::BCard* card = new BAppearanceKit::BCard("info",
	BAppearanceKit::B_CARD_PANEL);
BLayoutBuilder::Group<>((BGroupLayout*)card->GetLayout())
	.Add(new BStringView("title", "Processors"))
	.Add(new BStringView("value", "2"));
See also BActionCard BPageHeader Interface guidelines: Cards

BCardStrip

class
Declared in<CardStrip.h>
Librarylibr5ui.so
Derived fromBView, BInvoker
First userSettings, Game controllers (one card per controller)

BCardStrip shows a horizontal row of cards where the user picks one item. Each card is a BCardStripItem with a picture, a bold title, and one subtitle line.

Clicking a card or pressing the Left and Right arrow keys selects it and sends the strip's message with an "index" field. When the cards do not fit, the strip scrolls sideways with the mouse wheel, end arrows, or arrow keys.

When the strip has no items, it shows one dashed placeholder card with a title, a subtitle, and an optional action button. Colors come from ui_color() so it follows dark mode, and sizes scale with the plain font.

Use it for

Choosing one of a few items that each have a picture: game controllers, Bluetooth devices, sound outputs.

Not for

A long row-by-row list (use BListView or BSidebar), a container with controls (BCard), or a single clickable card (BActionCard).

BCardStrip(const char* name, BMessage* selectionMessage = NULL);

The strip owns the message. Its target is the window unless SetTarget() says otherwise.

bool AddItem(BCardStripItem* item); bool AddItem(BCardStripItem* item, int32 index); BCardStripItem* RemoveItem(int32 index); void MakeEmpty(); int32 CountItems() const; BCardStripItem* ItemAt(int32 index) const; int32 IndexOf(const BCardStripItem* item) const; void InvalidateItem(int32 index);

The strip owns an added item and deletes it; an item belongs to one strip. The caller owns a removed item. The chosen card stays chosen when a card before it comes or goes.

void Select(int32 index); int32 CurrentSelection() const; void ScrollToSelection();

Chooses a card without sending the message; -1 chooses none. The mouse and the keys send it, once per change.

BSize PictureSize() const;

The size a card shows its picture at, for the current font size. Render pictures at this size.

void SetEmptyText(const char* title, const char* subtitle); void SetEmptyAction(const char* label, BMessage* message);

The dashed card while the strip is empty, and a button on it whose message goes to the strip's target. A NULL label removes the button.

#include <CardStrip.h>

BAppearanceKit::BCardStrip* strip = new BAppearanceKit::BCardStrip("controllers",
	new BMessage(kMsgChosen));
strip->SetEmptyText("No controller", "Plug one in with USB, or pair one in Bluetooth.");
strip->SetEmptyAction("Open Bluetooth…", new BMessage(kMsgBluetooth));

BSize size = strip->PictureSize();
BBitmap* picture = BGameControllerView::PictureBitmap(vendor, product, family,
	size.width, size.height, ui_color(B_DOCUMENT_TEXT_COLOR));
strip->AddItem(new BAppearanceKit::BCardStripItem("DualSense Wireless Controller",
	"Bluetooth · 80 %", picture));
delete picture;

// In MessageReceived(): message->FindInt32("index", &index)
See also BCardStripItem BCard BActionCard BGameControllerView::PictureBitmap()

BCardStripItem

class
Declared in<CardStripItem.h>
Librarylibr5ui.so
Derived fromBArchivable
First userSettings, Game controllers

One card of a BCardStrip: a picture, a title, and one subtitle line.

It is not a view: the strip draws it. The picture is copied; the item does not load one. A change redraws the card.

BCardStripItem(const char* title, const char* subtitle = NULL, const BBitmap* picture = NULL);
void SetTitle(const char* title); void SetSubtitle(const char* subtitle); void SetPicture(const BBitmap* picture); const char* Title() const; const char* Subtitle() const; const BBitmap* Picture() const;

SetPicture() copies the bitmap; NULL removes it. Best at BCardStrip::PictureSize(); a larger one is scaled down in shape.

See also BCardStrip
