Aomi · Web Engine Contract

BWebContentView

The page view that separates Aomi’s native R5 window from its web engine. Aomi talks only to BWebContentView and BWebSession, never to engine-specific headers. Servo (BServoContentView) loads libr5servo.so dynamically through dlopen().

Overview

Declared in: distro/apps/aomi/WebContentView.h (MIT)
Derived from: public BView
Implementation: BServoContentView in distro/apps/aomi/ServoContentView.cpp

The view is always opaque (white default background); window glass belongs to the chrome, never to web content. Any capability an engine does not implement returns B_NOT_SUPPORTED so the window can disable that action cleanly. New calls are appended at the end; shipped calls do not change.

BWebSession

class BWebSession {
public:
    BWebSession(bool privateSession);
    bool IsPrivate() const;
};

Describes whether a window is a normal or private session. Normal windows share one process and one Servo, on an engine thread, with the profile in ~/config/settings/Aomi/Servo. A private window runs in a process of its own; its Servo keeps cookies and site data in memory only.

Reported Messages

All engine notifications are delivered to the registered BMessenger using fixed 4-byte message codes:

  • AOMI_LOAD_STARTED ('aLdS'), AOMI_LOAD_COMMITTED ('aLdC'), AOMI_LOAD_FINISHED ('aLdF'), AOMI_LOAD_FAILED ('aLdX')
  • AOMI_NAVIGATION ('aNav': canBack, canForward, loading)
  • AOMI_TITLE_CHANGED ('aTit'), AOMI_URL_CHANGED ('aUrl'), AOMI_FAVICON ('aFav'), AOMI_HOVER_LINK ('aHov')
  • AOMI_SECURITY ('aSec': AOMI_SECURITY_*), AOMI_PROTOCOL ('aPrt': "h2", "http/1.1", "h3")
  • AOMI_PROGRESS ('aPrg': 0.0–1.0), AOMI_CURSOR ('aCur'), AOMI_FULLSCREEN ('aFsc')
  • AOMI_NEW_WINDOW ('aNww'), AOMI_CLOSE_WANTED ('aClw'), AOMI_DIALOG ('aDlg': kind AOMI_DIALOG_*, text, where). For the listener’s information: the view itself asks the user and answers the page (alert, confirm, prompt, sign-in, file upload, context menu, select list).
  • AOMI_DOWNLOAD_ADDED ('aDla'), AOMI_DOWNLOAD_PROGRESS ('aDlp'), AOMI_DOWNLOAD_FINISHED ('aDlf'), AOMI_DOWNLOAD_FAILED ('aDlx')
  • Added 27 Nov 2026: AOMI_EXTERNAL_URL ('aExt': url), an address for another program such as mailto:; the page stays where it is and the window hands the address on. AOMI_DOWNLOAD_WANTED ('aDlw': url to fetch, text to show), a link to a file the engine cannot show. AOMI_DIALOG_LEAVE is now asked (a page with a beforeunload handler).

Engine Factory & Fallback

status_t aomi_engine_start(const char* engine);
BWebContentView* create_aomi_content_view(const char* engine,
    const char* name, BWebSession* session);

Aomi calls aomi_engine_start("Servo") once at startup and creates every tab view via create_aomi_content_view("Servo", "page", session). Because libr5servo.so is loaded via dlopen(), removing the library does not crash Aomi: the view shows a clear message that the web engine could not start and how to restore the r5servo package. The view draws Servo's frame at its own size, never stretched. Servo runs one engine per process, so Aomi opens every further window as its own process.
