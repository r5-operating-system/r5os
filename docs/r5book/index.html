Building on LibR5

R5Book is the developer guide to what R5 Operating System adds next to libbe: the LibR5 libraries, guides for building R5 apps and Settings pages, and additions to Haiku kits. It follows the Be Book layout: one entry per class, with where it is declared, what it derives from, and its member functions.

What is in this page

  • Kits — One page per library, alphabetical.
  • Guides — Settings modules, accounts, Vulkan, and UI guidelines.
  • Reference — Additions to Haiku kits and the full class & call index.
  • Linking a program — Headers, libraries, and Jamfile rules.
  • Rules for LibR5 — Additive ABI, MIT license, sharp icons, system colors.
Pictures. Most pictures in this edition are HTML mockups, drawn with the R5 system colors and sizes at the 12 point system font. Sign in, the lock screen and the Wi-Fi page are already screenshots taken from R5; the mockups will be replaced the same way. Each picture says which one it is.

Cards, page headings, the Settings sidebar, the screen picture, account cards and lists, the password field, the accent button, and the icon view.

Bluetooth Kit

The Bluetooth page of Settings, the controller behind it, and the Bluetooth switch, for any program that wants to show radios or find devices nearby.

 libr5game.so · <GameController.h>

Game Kit

Game controllers with named buttons and sticks, their battery and button labels, plug and unplug messages, and a live picture of the controller.

 libr5icons.so · <R5Icons.h>

Icons Kit

Haiku's own icons as bitmaps, icon buttons that match a text button, and line glyphs such as power, restart and the password eye, drawn in the text color.

MIDI 2 Kit

MIDI 2.0 in Haiku's own MIDI kit: the Universal MIDI Packet, 16-bit velocities and 32-bit controllers, Property Exchange, Profiles and endpoint discovery.

 libr5power.so · <PowerRoster.h>

Power Kit

The batteries, the power source, the processor's profile and sleep, with a message when one of them changes, and the machine's power settings through the power service.

 libr5security.so · <R5Security.h>

Security Kit

Argon2id password hashing and key derivation, authenticated encryption for files and buffers, wiped secret memory, and cryptographic random bytes.

 libr5wifi.so · <R5WiFi.h>

Wi-Fi Kit

The Wi-Fi panel of Settings and the WiFi program, the state machine behind it, and the Wi-Fi arcs, for any program that wants to show or drive Wi-Fi.

Next to libbe, not inside it

A Haiku program that links only libbe keeps working, and keeps its ABI. LibR5 adds parts Haiku does not have; it does not rename or replace a libbe call. The classes follow the Haiku conventions: a B prefix, archiving with Archive() and Instantiate(), colors from ui_color(), and sizes that follow the system font.

Rules for LibR5

  • Additive. A new function or class is added at the end. A function that shipped keeps its arguments. A numbered value, such as R5_ICON_HOME, keeps its number.
  • MIT. The libraries and their headers are MIT, so any program can link them. Code added to them must be MIT-compatible.
  • Shared. A helper written for R5 and used by more than one program goes in one of these libraries, with its entry in this book and in docs/LIBR5.md in the same change.
  • Sharp. An icon is rendered at the size it is shown and drawn pixel for pixel. Stretching a bitmap by even one pixel makes its edges jagged; use BIconView.
  • System colors. Every color comes from ui_color(), so a part follows the user's colors and dark mode.
