Functions & effects

Drawing helpers for screens and account avatars, plus window shadow and frosted glass controls.

First userDisplay, Notifications, Desktop and Deskbar, Sign in
BRect r5_screen_draw(BView* view, BRect bounds, rgb_color contentColor);

The screen frame Settings uses, in a 4:3 shape centered in bounds, filled with contentColor. It returns that fill, in the view's coordinates, so the caller can draw a Deskbar or a notification on the glass.

void r5_screen_caption(BView* view, BRect content, const char* text, rgb_color textColor);

One centered line on the glass. Text that does not fit is skipped.

void r5_avatar_draw(BView* view, BRect circle, const BBitmap* icon, bool highlighted); float r5_avatar_icon_side(float circleSide);

An account picture: a round plate with a thin ring and the icon in the middle. Highlighted is the light accent plate; otherwise the plate and the picture are gray. A bitmap of r5_avatar_icon_side() pixels is drawn pixel for pixel; any other size is filtered. Without an icon a plain person outline is drawn.

float side = r5_avatar_icon_side(44);
BBitmap* people = r5_mime_icon_bitmap("application/x-vnd.Be-PEPL", side);
r5_avatar_draw(this, BRect(0, 0, 43, 43), people, true);

Window effects

<WindowEffects.h>
Declared in<WindowEffects.h>
Librarylibr5ui.so
First userAppearance (Look and feel), Settings

The shadow and the frosted glass of windows, shown in the GPU mode only. These are free functions in BAppearanceKit, like ui_color(): each sends one message to app_server.

In CPU mode every call is accepted and stored and nothing changes on screen. B_TRANSPARENT_COLOR keeps meaning "do not erase" and never becomes glass. First user: the "Window effects" box on Look and feel, in Settings and in the Appearance program.

uint32 window_effects(); status_t set_window_effects(uint32 effects);

The user's choice of B_WINDOW_SHADOW, B_WINDOW_FROSTED_GLASS and B_WINDOW_ANIMATIONS, for the whole desktop. app_server keeps it with its other appearance settings. Only Settings and the Appearance program set it.

enum window_effect_strength window_effect_strength(); status_t set_window_effect_strength(enum window_effect_strength strength);

One step for the shadow and the glass: B_WINDOW_EFFECTS_QUIET, B_WINDOW_EFFECTS_BALANCED (the default) or B_WINDOW_EFFECTS_GLASSY. The function has the name of the type, as stat() has that of struct stat, so the type is written enum window_effect_strength.

status_t set_window_glass(BWindow* window, bool glass); status_t set_view_glass(BView* view, bool glass);

A program asks for glass behind its own content. The view's background is drawn with alpha 0 and the blur behind the window shows through. What the view draws with B_OP_ALPHA and B_ALPHA_COMPOSITE keeps its alpha; every other mode stays opaque. The view must be attached and its window locked.

#include <WindowEffects.h>

MyWindow::MyWindow()
	: BWindow(BRect(100, 100, 500, 400), "Glass", B_TITLED_WINDOW, 0)
{
	BAppearanceKit::set_window_glass(this, true);
}
status_t set_window_corner_radius(BWindow* window, float radius);

A program rounds the corners of its own window, the radius in pixels (0 is square, the default; at most 64). Use it for a window without a title tab, such as a panel or a floating bar; a titled window gets its corners from the decorator the user chose. The window's frame stays the same rectangle: the corners are only taken out of what the window shows and what it gets clicks for. With the GPU the arc is smooth; without it (Lavapipe without effects, Safe mode) the arc is stepped, and the desktop behind shows in the corner either way. Content in a corner is clipped. A round window gets the full soft shadow of the chosen effect step, and the line its window frame draws along the edge runs on round the corner. Scale the radius with the font size, like other R5 measures: 18 at 12 points.

#include <WindowEffects.h>

PanelWindow::PanelWindow()
	: BWindow(BRect(100, 100, 400, 160), "Panel", B_BORDERED_WINDOW, 0)
{
	float radius = roundf(18.0f * be_plain_font->Size() / 12.0f);
	BAppearanceKit::set_window_corner_radius(this, radius);
}
