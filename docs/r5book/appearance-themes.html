Theming

A theme is a saved combination of parts that already exist: the window frame, the controls, the scroll bars, the Deskbar, light or dark with an accent colour, and the window effects. There is no drawing engine. A program that draws with be_control_look and ui_color() follows every theme, light and dark, without a line of theme code.

For developers

guide

R5 themes work the BeOS and Haiku way: the system draws the controls, and the colours are named, not fixed. Do these four things and a program looks right in R5 Modern, R5 and Classic (Haiku), light and dark, with the GPU and in Safe mode:

  • Use the system controls. BButton, BTextControl, BCheckBox, BMenuField, BListView in a BScrollView, BSlider, BTabView. A theme changes how they are painted, never their size.
  • Draw your own parts with be_control_look. A view that paints a button face, a frame or a check mark itself calls the same BControlLook method the system control calls (DrawButtonFrame(), DrawTextControlBorder(), DrawCheckBox()…), and asks it for the insets.
  • Name colours with ui_color(). SetViewUIColor(B_PANEL_BACKGROUND_COLOR), SetHighUIColor(B_PANEL_TEXT_COLOR); a list or a document uses B_LIST_* or B_DOCUMENT_*. Never a fixed grey or white: in dark mode it stays light.
  • Decide light or dark from the panel. When a colour of your own must differ (a picture, a shade), test ui_color(B_PANEL_BACKGROUND_COLOR).IsDark(), and draw again on B_COLORS_UPDATED (a view gets it, and is invalidated, on its own).
void
SwatchView::Draw(BRect updateRect)
{
	rgb_color panel = ui_color(B_PANEL_BACKGROUND_COLOR);
	// a thin line that reads in light and in dark
	SetHighColor(tint_color(panel, panel.IsDark() ? B_LIGHTEN_1_TINT : B_DARKEN_2_TINT));
	StrokeRect(Bounds());

	BRect frame(10, 10, 110, 34);
	be_control_look->DrawButtonFrame(this, frame, updateRect,
		ui_color(B_CONTROL_BACKGROUND_COLOR), panel);
	be_control_look->DrawButtonBackground(this, frame, updateRect,
		ui_color(B_CONTROL_BACKGROUND_COLOR));
}

A program does not link libr5ui.so for this. Only a program that chooses a theme (Settings, a test tool) calls Themes.h.

The parts

overview
WindowsA decorator add-on: Default (R5 Modern), Default (R5), or Haiku's built-in Classic (Haiku). See Decorator hooks.
ControlsA BControlLook add-on: R5 Modern, or Haiku's built-in controls (Be and Flat are in haiku_extras).
ScrollbarsThe R5 Modern scroll bars or Haiku's, with Haiku's single or double arrows (scroll_bar_info). The width stays Haiku's.
DeskbarDefault (R5) (Vertical, Compact or Horizontal, rounded, away from the screen edges) or Classic (Haiku).
Mode and accentLight or dark, and the accent: a ui_color set.
EffectsShadow, frosted glass, animations and their strength (Window effects).

Built-in themes: R5 Modern and R5, light and dark, and Classic (Haiku), light only, exactly as Haiku. The default is R5, light. The user chooses on the Theme page of Settings (Personalization), and can save a combination as a theme of their own.

The R5 Modern controls

control look
Add-on/system/add-ons/control_look/R5ModernControlLook
ClassBPrivate::R5ModernControlLook, on top of HaikuControlLook (like Haiku's FlatControlLook)
LicenseMIT

Flat faces with round corners that follow the font size: buttons and fields round 7 at 12 points, check boxes round 4 filled with the accent and a white tick, radio buttons a white dot on the accent, boxes and tabs round 8, a selected menu item a round accent face, the scroll bar a round track with a round thumb, the slider a thin round bar with a white disc. The default button is the accent with a white label; a focused field has the accent line and a soft ring. Every frame and background inset is Haiku's, so a window lays out the same with either look. Every colour is a ui_color.

Dark mode

guide

Dark mode is a ui_color set: the panel #1f232b, text #e6e9ef, fields #15181e, controls #2a2f39, the window tab the deeper yellow #e8b923. Every part decides with the panel colour: the controls draw with the colours they are given, the decorators read the tab and border colours (Default (R5 Modern) also softens its edge line), and Deskbar's Default (R5) style takes dark glass with the GPU and an opaque #1c2029 without it. In Safe mode the colours are the same, the surfaces opaque, the corners stepped.

Live switching

behaviour

A new theme reaches running programs at once. Colours always did (B_COLORS_UPDATED). For the controls, set_theme() sends B_COLORS_UPDATED with an int64 "r5:control_look" to every program; each program's windows load the control look app_server names now and draw again. Nothing is added to the libbe API or ABI. The previous look stays in memory until the program quits, because another window may still be drawing with it.

#include <Themes.h>

using namespace BAppearanceKit;

theme_info theme;
if (find_theme("R5 Modern", &theme) == B_OK) {
	theme.mode = B_THEME_DARK;
	set_theme(&theme, theme.parts | B_THEME_COLORS);
}

Theme files

format

A saved theme is driver settings text in ~/config/settings/r5/themes/, short enough to mail. A key that is not there is a part the theme does not hold.

name "Evening"
windows "R5ModernDecorator"
controls "R5ModernControlLook"
scroll_bars modern
arrows single
deskbar_style r5
deskbar_layout vertical
mode dark
accent #7c4ddb
