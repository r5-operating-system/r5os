Making themes

How to make a theme of your own, and the parts that go in one: a theme file, a control look add-on, a decorator. A theme combines parts that already exist; it never draws anything itself. Read Theming first for what a theme is and how a program follows one.

What a theme is

guide

A theme names its parts: the window decorator, the control look, the scroll bar style, width and arrows, the Deskbar style, light or dark with an accent, and the window effects. Each part is a normal Haiku add-on or setting, so every program keeps working unchanged. A theme may hold only some parts; applying it leaves the others as they are. R5 has three built-in themes (R5 Modern, R5, Classic (Haiku)); the user's own are on the Theme page of Settings next to them.

The theme file

format 1

Driver settings text, one key per line. The sample is docs/theme-kit/Evening in the source tree. Put a file in ~/config/settings/r5/themes/ and it is a card on the Theme page.

# R5 theme
format 1
name "Evening"
windows "R5ModernDecorator"
controls "R5ModernControlLook"
scroll_bars modern
arrows single
scroll_bar_width 10
deskbar_style r5
deskbar_layout vertical
deskbar_rounded true
deskbar_floating true
mode dark
accent #8f63e6
formatThe version, 1. Keys are only ever added; a reader takes older formats and the keys it knows of a newer one.
windows, controlsAn add-on's file name in add-ons/decorators or add-ons/control_look (system, home or non-packaged); "" is Haiku's own. A path is refused.
scroll_bars, arrows, scroll_bar_widthmodern or haiku; single or double; 8 to 32 at 12 points.
deskbar_*Style r5 or classic, layout, rounded, away from the screen edges.
mode, accentlight or dark; #rrggbb or default.
shadow, glass, animations, strengthThe window effects.

A control look

add-on

A control look is a BControlLook add-on, the same kind Haiku has (Be, Flat). Start from the template ExampleControlLook (distro/desktop/src/add-ons/control_look/ExampleControlLook/): a class on top of HaikuControlLook that overrides only what it draws differently, and the entry point:

extern "C" BControlLook*
instantiate_control_look(image_id id)
{
	return new(std::nothrow) BPrivate::ExampleControlLook();
}
  • Keep the sizes. Every Draw*() method insets rect exactly as Haiku's does, and only on the sides in borders (a spinner's buttons and a tab view's plain border name some sides only). Then a window lays out the same with every look, and nothing moves on a switch.
  • Colours from the caller and ui_color(). The face is the base the control passes; lines are B_CONTROL_BORDER_COLOR, fields B_DOCUMENT_BACKGROUND_COLOR, the accent B_CONTROL_HIGHLIGHT_COLOR.
  • Scale with the font. Radii and widths at 12 points times be_plain_font->Size() / 12.
  • No GPU. Draw with the BView calls; Painter draws the same shapes in Safe mode.

Build it with an Addon rule linking be, copy it to ~/config/non-packaged/add-ons/control_look/, and choose it under Parts › Controls. Running programs switch to it at once.

The scroll bar width

BControlLook
virtual float GetScrollBarWidth(orientation orientation = B_VERTICAL);

Haiku's hook; BScrollBar and BScrollView ask it for their size, so the width of every scroll bar laid out by them follows your look. Scale it with the font. R5 Modern reads scroll_bar_width from the theme (Thin 10, Haiku's 14, Wide 18 on the page); a program that places scroll bars with the constant B_V_SCROLL_BAR_WIDTH keeps Haiku's width and still works.

Where a menu bar starts

BControlLook
virtual void GetBackgroundInsets(background_type backgroundType, uint32 flags, float& _left, float& _top, float& _right, float& _bottom);

Haiku's hook. For B_MENU_BAR_BACKGROUND Haiku returns 1 on each side. A larger left inset moves the first title of a menu bar in by the difference, in R5's BMenuBar, when the bar is on the left edge of a window with a frame; the open menu follows its title. R5 Modern returns 8 more at 12 points, so the titles clear its round window corner. Return Haiku's value when your windows have square corners.

The R5 menu style

BControlLook

Return more than 1 for B_MENU_BACKGROUND and R5's BMenu lays out its menus in the R5 menu style: that inset is the space inside the menu window, and the B_MENU_ITEM_BACKGROUND inset is the padding round an item's content (R5 Modern: 5, and 11, 9 and a row of 26 at 12 points). The menu window gets round corners and the shadow with the GPU; its view has the menu colour, so DrawMenuBackground() draws nothing (the line is the decorator's), and DrawMenuItemBackground() only the highlight. The shortcut is text, the check mark and the dot are drawn by BMenuItem, the submenu arrow by your DrawArrowShape(). Return Haiku's 1 and menus stay Haiku's.

A window decorator

add-on

The window frame and tab are an app_server decorator add-on in add-ons/decorators (Default (R5), Default (R5 Modern)). Take the colours from DesktopSettings::UIColor() (B_WINDOW_TAB_COLOR, B_WINDOW_BORDER_COLOR, the inactive ones) and decide light or dark from B_PANEL_BACKGROUND_COLOR, so a theme's dark set gives a dark frame. Round corners, the edge line and glass go through the decorator hooks: see Decorator hooks.

Light and dark

guide

Dark mode is a ui_color set. A part that uses only named colours is dark the moment the set is. Where a part needs a colour of its own (a shade, a glass tint), test ui_color(B_PANEL_BACKGROUND_COLOR).IsDark() and pick the light or dark value; never a fixed grey or white that stays light in dark mode.

Testing

checklist
  • Light and dark: r5-effects-test theme mode dark, then light.
  • With the GPU (shadow, glass) and in Safe mode (the CPU, Painter, opaque surfaces).
  • At font size 12 and 18 (Appearance › Fonts).
  • A window of every control: r5-effects-test controls; switch while it is open.
  • Spinners, tab views, menus, lists with scroll bars, a default button, a disabled control.
  • The scroll bar width: r5-effects-test theme width 18.

Sharing a theme

guide

A theme is one small text file: send it, and the other person copies it to ~/config/settings/r5/themes/. If the theme uses an add-on of your own, send the add-on too, for ~/config/non-packaged/add-ons/. A theme that names an add-on the other computer does not have leaves that part as it is. Export and Import on the Theme page, and themes in HaikuDepot, are later steps.
